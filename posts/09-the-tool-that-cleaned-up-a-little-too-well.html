The Tool That Cleaned Up a Little Too Well

January 2021 - tags: config-management, monitoring

A routine sync of switch configurations wiped out settings nobody had told the syncing tool about in the first place.

What Happened

Monitoring for an entire site went dark, with virtualization hosts falsely appearing offline. While resolving an unrelated sync issue on other switches, a resync operation on the management platform erased interface configurations that had been applied directly through the command line rather than through the platform's own templates.

The Fix

The lost interface configurations were restored from a separate network backup system, and monitoring came back once they were reapplied.

Jargon, Decoded

A configuration management platform is meant to be the single source of truth for how devices are set up, but it can only protect settings it actually knows about. Anything configured outside that system is invisible to it, right up until the system helpfully overwrites it during a routine sync.

Lessons Learned

If a tool is supposed to manage a device, every change to that device needs to go through the tool, no side doors. The fix here was updating the standard templates so future changes would not need an unmanaged workaround in the first place.
