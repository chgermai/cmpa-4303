The Cable That Was Plugged In Wrong, on Paper

June 2020 - tags: link-aggregation, broadcast

A same day router swap left a network connection configured just wrong enough to break playback for a national sports feed.

What Happened

A live sports broadcast started returning errors shortly after an edge router was swapped from one vendor's hardware to another's as part of planned maintenance. The new router's connection to a downstream network appliance had been set up with a slightly incorrect configuration for how the multiple physical links should work together as one logical connection.

The Fix

Once identified, the configuration was corrected and the logical connection came back online, restoring playback about twenty five minutes after the initial report.

Jargon, Decoded

When several physical network cables are meant to act as one combined, faster connection, that only works if both ends agree on exactly how to bundle them. Get that agreement even slightly wrong and the two ends might as well be speaking different dialects of the same language.

Lessons Learned

A hardware swap is never really finished the moment the new box powers on, it is finished once someone verifies every downstream dependency still behaves the way it used to. A short, deliberate post change check would have caught this before viewers did.
